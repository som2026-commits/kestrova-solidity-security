# solidity-security-review (Kestrova)

Claude Code plugin: the `solidity-security-review` skill plus the `kestrova` remote MCP server
(`.mcp.json`). Install: `/plugin marketplace add som2026-commits/kestrova-solidity-security`, then `/plugin install solidity-security-review@kestrova`.
See the repository README for other agents, payment rules and limits. Not an audit. MIT.
